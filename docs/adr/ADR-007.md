# ADR-07: Diseño visual, navegación por rol y retroalimentación de usuario

## Requerimientos relacionados

RF-01, RF-03, RF-04, RF-05, RF-06, RF-07, RF-08, RF-09, RF-10, RF-11, RF-12, RF-13, RNF-04.

## Contexto

Muchos veedores son adultos mayores y con poca experiencia tecnológica. Debe haber una interfaz con feedback visual claro para acciones en proceso, exitosas, fallidas y validaciones usando Lottie y Reanimated, evitando modales genéricos y procurando que sea intuitiva para el usuario.

## Decisión

**REACT NAVIGATION, @GORHOM/BOTTOM-SHEET, LOTTIE-REACT-NATIVE, REACT-NATIVE-REANIMATED, UNIWIND.**

## Consecuencias

Es tener una mayor gama de estilos, con interfaz más intuitiva para el usuario.
